# 03 지도 변환 규칙

OSM의 각 요소가 게임에서 무엇이 되는지 정의한다. 이 규칙을 실제로 수행하는 도구는 [13 데이터 파이프라인](13_data_pipeline.md)에 있다.

대원칙 두 가지는 [확정]이다.

- 도로는 공이 지나가는 통로다.
- 다양한 폴리곤이 벽돌이 된다.

그 아래 세부 규칙은 모두 [제안]이다.

## 블록 구조

OSM의 도로는 면이 아니라 선이고, 건물 사이에는 마당이나 주차장 같은 빈 땅이 많다. 그대로 쓰면 공이 도로 밖으로 새어 "도로가 통로"라는 원칙이 무너진다. 그래서 다음과 같이 변환한다.

1. 도로 중심선에 등급별 폭을 주어 **통로**를 만든다.
2. 통로로 둘러싸인 영역 하나하나를 **블록**으로 만든다. 블록은 처음에 통째로 솔리드다.
3. 블록 안을 건물별 **셀**로 빈틈없이 나눈다. 건물이 없는 자투리 땅은 가장 가까운 건물의 셀에 포함한다.
4. 공이 블록 가장자리에 맞으면 그 지점의 셀(건물)이 피해를 받는다. 건물이 부서지면 셀이 꺼져 공이 들어갈 수 있다.

결과적으로 공은 처음에 도로로만 다니고, 건물을 부술수록 블록 안쪽으로 파고든다.

## 요소별 역할

| OSM 요소 | 주요 태그 | 게임 역할 |
|---|---|---|
| 도로 | `highway=*` | 통로 |
| 건물 | `building=*` | 벽돌 |
| 랜드마크 | 건물 중 수작업 지정 | 보스 벽돌 |
| 물 | `natural=water`, `waterway=*` | 해저드. 공이 빠지면 잃는다 |
| 다리 | `bridge=yes` | 물 위의 통로 |
| 공원, 숲 | `leisure=park`, `landuse=forest` | 열린 공간. 나무는 1타 핀 |
| 지하철역 | `railway=station`, `station=subway` | 워프 입구 |
| 회전교차로 | `junction=roundabout` | 스피너 |
| 시설 | `amenity=*`, `shop=*` | 숨은 아이템 ([05](05_items.md)) |

## 도로 폭

실제 폭을 그대로 쓰면 공이 다니기에 너무 좁다. 등급만 살리고 폭은 과장한다.

| 도로 등급 | `highway` 값 | 통로 폭 (공 지름 대비) |
|---|---|---|
| 대로 | motorway, trunk, primary | 4배 |
| 중로 | secondary, tertiary | 3배 |
| 소로 | residential, unclassified | 2배 |
| 골목 | service, footway, pedestrian | 통로로 만들지 않음. 블록에 흡수 |

## 건물 HP

| 층수 | HP |
|---|---|
| 1~3층 | 1 |
| 4~10층 | 2 |
| 11~25층 | 3 |
| 26층 이상 | 4 |
| 랜드마크 | 스테이지에서 개별 지정 |

층수는 `building:levels`에서 가져오고, 없으면 `height ÷ 3`으로, 그것도 없으면 건물 용도와 바닥 면적으로 추정한다. 추정값은 기획자가 스테이지별로 덮어쓸 수 있다.

## 건물 정리

- 바닥 면적이 기준 이하인 건물은 이웃 건물과 합친다. 스테이지당 벽돌 수는 80~250개를 목표로 한다.
- 윤곽선은 단순화한다. 공의 반사를 예측할 수 있어야 하기 때문이다.

## 제외하거나 보호하는 시설

다음은 벽돌로 만들지 않거나 부술 수 없게 둔다. 이유는 [11 아트와 오디오](11_art_audio.md)의 톤 항목에 있다.

- 종교시설 (`amenity=place_of_worship`)
- 추모시설 (`historic=memorial`)
- 병원 (`amenity=hospital`)
- 문화재
