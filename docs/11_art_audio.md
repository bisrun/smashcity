# 11 아트와 오디오

모든 항목은 [제안]이다.

## 톤

실제 도시를 부수는 게임이므로 톤을 잘못 잡으면 불쾌하거나 문제가 될 수 있다. 다음을 지킨다.

- 장난감 디오라마처럼 보이게 한다. 책상 위의 모형 도시를 무너뜨리는 느낌이다.
- 사람, 차량 탑승자, 불, 사실적인 연기와 먼지를 그리지 않는다.
- 건물은 블록이나 종이 조각처럼 부서진다.
- 종교시설, 추모시설, 병원, 문화재는 부수지 않는다([03 지도 변환 규칙](03_map_conversion.md)).
- 실제 참사가 있었던 장소는 스테이지 후보에서 신중히 검토한다.

## 비주얼

실제 도시를 그대로 옮기지 않는다. 실제 지도를 뼈대로 삼아 상상으로 꾸민, 더 예쁜 도시를 그린다. [확정]

화면 샘플의 파스텔 스타일을 출발점으로 제안한다. [제안]

| 요소 | 방향 |
|---|---|
| 전체 | 밝은 파스텔의 장난감 마을. 부드러운 그림자 |
| 셀 | 구획의 윤곽 자체가 건물 한 채다. 아래 "벽돌이 벽돌로 보이게" 참고 |
| 작은 건물 | 하나하나 그리지 않는다. 블록마다 큼직한 건물 몇 채로 바꾼다 |
| 큰 건물 | 밝은 벽에 색 지붕. 높이대별로 색 계열을 달리해 HP가 읽히게 한다 |
| 빈 땅 | 나무와 구조물로 채운다. 뜻 없는 작은 집을 늘어놓지 않는다 |
| 통로 | 크림색 바닥 위에 연회색 찻길 띠와 흰 차선. 길가에 작은 가로수와 가로등, 찻길에는 승용차, 택시, 버스 대신 밴, 경찰차, 소방차 같은 차 모델 열 가지가 달린다. 차는 그림일 뿐이고 공은 그 위를 지나간다 |
| 호수 | 물가에 수련, 물 한가운데에 카누 |
| 공원 | 네 곳 중 한 곳에 조각상 |
| 패들 | 배 모양. 앞뒤가 뾰족한 선체에 갑판, 선실, 굴뚝, 깃발 |
| 물 | 밝은 청록, 물가의 밝은 띠와 잔물결 |
| 랜드마크 | 금색. 꼭대기에 빛 |
| 상상 아이템 | 대관람차, 열기구, 무지개 문처럼 판에서 가장 눈에 띄는 색과 모양 |
| 공 | 흰색에 짙은 테두리. 어떤 바닥에서도 보여야 한다 |
| 시간대 | 스테이지마다 낮, 노을, 밤을 달리할 수 있다 |

HP는 건물의 높이와 지붕 위의 숫자 표지로 읽힌다.

꾸밈이 늘수록 공과 통로가 묻힐 수 있다. 꾸밈은 셀 위에만 두고 통로 위는 비운다. 통로를 가로지르는 것은 무지개 문처럼 게임에서 역할이 있는 것만 둔다.

도시마다 그 도시다운 상상을 넣는다. 서울은 벚꽃과 대관람차, 다른 도시는 그 도시의 것으로 한다.

다른 게임의 모습을 따라 그리지 않는다. 실제 지도 위에 상상의 층을 얹는다는 구조만 참고한다.

## 벽돌이 벽돌로 보이게

작은 건물과 나무를 그대로 늘어놓으면 점이 흩어진 것처럼 보여, 배경도 아니고 벽돌도 아닌 것이 된다. 벽돌 하나하나가 덩어리로 읽혀야 한다. [확정]

블록 위에 건물을 따로 올리지 않는다. 블록의 윤곽 자체를 건물로 올리고 지붕만 그럴듯하게 얹는다. 캐주얼 3D 게임에 나오는 건물과 나무 같은 모습을 목표로 한다. [확정]

지금은 다음과 같이 그린다. [제안]

| 장치 | 내용 |
|---|---|
| 몸통 | 구획의 윤곽이 그대로 건물의 벽이다. 파스텔 벽에 층마다 하늘색 창문을 격자로 낸다. 창 하나의 폭은 12m쯤이다 |
| 밑동 그늘 | 건물 둘레의 바닥에 어두운 띠를 깔고 맨 아래 벽을 어둡게 해, 건물이 땅에 붙어 보이게 한다 |
| 틈 | 윤곽을 5m 안으로 들여 이웃 건물과 틈을 둔다. 작은 길이 건물 사이의 골목으로 보인다 |
| 높이가 HP | 남은 HP만큼 단이 쌓인다. 한 단을 26m로 높게 잡아, 맞을 때마다 건물이 쿵 하고 눈에 띄게 줄어든다. [확정된 방향] 공은 높은 건물에 가려도 보이게 그린다 |
| 집 지붕 | HP가 낮은 작은 구획은 처마 위에 뾰족지붕과 굴뚝 |
| 기와지붕 | 중간 구획은 층층이 좁아지는 색 지붕 |
| 평지붕 | HP가 높은 구획은 색 테두리 안의 밝은 옥상에 표지판 원, 옥탑, 물탱크, 화분 |
| 공원 | 건물이 없던 낮은 구획은 낮은 화단에 큰 나무 |
| 랜드마크 | 금빛 받침 위에 위로 좁아지는 유리 탑. 실제 윤곽을 쓴다 |
| 숫자 표지 | 지붕 위에 남은 타격 수를 크게 쓴다. 흰 숫자에 색 테두리를 두르고, 테두리 색은 2는 초록, 3은 주황, 4는 빨강, 5 이상은 보라. 블록이 클수록 숫자도 크다. 숫자 뒤에 원은 두지 않는다. 한 번 남은 블록에는 띄우지 않는다 |
| 부서진 자리 | 건물이 있던 윤곽이 바닥에 옅은 터로 남는다. 판이 휑해 보이지 않고 어디가 뚫렸는지 읽힌다. [확정] |
| 깨지지 않는 벽 | 회색 돌담. 구멍 양쪽에 빨간 지붕의 문기둥 |

앞서 해 본 것: 두툼한 받침 블록 위에 큼직한 건물 몇 채를 올리는 방식, 블록마다 건물 하나를 크게 올리는 방식. 받침과 건물이 따로 놀아 버렸다.

## 밖에서 가져올 수 있는 재료

건물과 환경 에셋을 가져와 라이브러리처럼 써도 된다. [확정] 구할 수 있는지 알아본 결과는 다음과 같다(2026-11-24 검색).

| 묶음 | 내용 | 이용 조건 |
|---|---|---|
| [Kenney City Kit (Commercial)](https://kenney.nl/assets/city-kit-commercial) | 상업 건물 50종 | CC0 |
| [Kenney City Kit (Suburban)](https://kenney-assets.itch.io/city-kit-suburban) | 주택, 울타리, 나무, 진입로 | CC0 |
| [Kenney Nature Kit](https://kenney.nl/assets/nature-kit) | 나무, 바위, 풀 등 330종 | CC0 |
| [KayKit City Builder Bits](https://kaylousberg.itch.io/city-builder-bits) | 도시 건설용 건물과 소품 | CC0 |
| [Quaternius LowPoly Buildings](https://opengameart.org/content/lowpoly-buildings-pack) | 건물 외관 | CC0 |

CC0는 출처 표기 없이 상업적으로 써도 되는 조건이다.

Kenney의 Nature Kit과 City Kit (Commercial)을 내려받아 확인했다. 둘 다 Godot이 바로 읽는 GLB 파일이 들어 있고, 이용 조건 파일에 CC0라고 적혀 있다.

지금 쓰는 것은 다음과 같다. 파일은 `assets/models/kenney/` 아래에 이용 조건 파일과 함께 있다.

| 쓰임 | 모델 | 묶음 |
|---|---|---|
| 둥근 나무 | tree_default, tree_oak, tree_fat, tree_detailed | Nature Kit |
| 뾰족한 나무 | tree_cone, tree_pineRoundA, tree_pineRoundC | Nature Kit |
| 덤불, 꽃, 바위 | plant_bush, plant_bushLarge, flower 3종, rock_largeA | Nature Kit |
| 옥상의 파라솔 | detail-parasol-a, detail-parasol-b | City Kit (Commercial) |
| 차 | sedan, taxi, suv, van, police, hatchback-sports, truck, delivery, ambulance, firetruck | Car Kit |
| 가로등 | light-square, light-curved | City Kit (Roads) |
| 카누, 수련, 조각상 | canoe, lily 2종, statue 4종 | Nature Kit |
| 건물 (꺼 둠) | building-a ~ n, building-skyscraper-a ~ e | City Kit (Commercial) |

가져온 모델을 노드로 하나하나 세우지 않는다. 삼각형과 색을 꺼내 블록의 메시에 함께 구워 넣는다(`src/render/model_library.gd`). 그래야 블록이 주저앉거나 부서질 때 함께 움직이고 그리는 횟수가 늘지 않는다.

Nature Kit의 나무는 잎이 민트색이라 이 판의 풀빛과 어긋났다. 잎 부분만 이 판의 초록과 벚꽃색으로 물들여 쓴다.

City Kit (Commercial)에는 옥상 소품이 파라솔과 차양뿐이었다. 물탱크, 실외기, 안테나 같은 것은 없어서 옥탑과 물탱크는 직접 만든 모양을 그대로 쓴다.

건물 모델은 네모에 가까운 구획에만 올릴 수 있다. 잠실에서 해 보니 277개 중 20개만 해당했고, 그 20개가 나머지와 생김새가 달라 따로 놀아 보였다. 그래서 꺼 두었다(`USE_MODEL_BUILDINGS`). 블록 전체를 네모로 바꾸는 방식도 해 봤으나 버렸다.

## 판을 둘러싼 풍경

패들, 지도, 그 사이의 공간이 따로 놀지 않고 한 장의 그림으로 어울려야 한다. [확정]

지도와 패들 사이는 강으로 그린다. 다각형을 잘라 붙인 것처럼 보이지 않게 다음과 같이 한다. [제안]

| 요소 | 방향 |
|---|---|
| 지도 쪽 강가 | 곧은 선이 아니라 굽이치는 선. 풀밭, 모래, 물거품 순으로 물에 닿는다. 나무를 드문드문 심는다 |
| 물 | 강가에서는 밝고 깊어질수록 짙어진다. 잔물결을 흩뿌린다 |
| 패들 | 강 위의 배 |
| 화면 아래쪽 강가 | 앞쪽 강가를 큰 나무와 함께 그려 그림의 아래를 받친다. 공이 빠지는 선과 맞춘다 |
| 판의 옆과 위 | 풀밭과 숲으로 감싸고, 위쪽 멀리 언덕을 둔다. 하늘색 바탕이 그 위로 이어진다 |

강이 없는 스테이지는 그 자리의 것으로 바꾼다. 큰 도로가 기준선이면 광장이나 공원, 철길이면 선로와 승강장으로 그린다.

이 공간은 공을 보고 반응하는 곳이므로 그림이 공을 가리면 안 된다. 물 위에는 잔물결 말고는 두지 않는다.

## 오디오

귀여운 소리를 낸다. [확정]

효과음은 녹음한 파일을 쓰지 않고 시작할 때 계산해서 만든다(`src/audio/sfx.gd`). 장난감 실로폰 같은 둥근 음색의 짧은 음을 미끄러지게 하거나 두세 개 이어 붙인 것이다. 파일이 없어 용량이 늘지 않고, 이용 조건을 따질 것도 없다. [제안]

| 일 | 소리 |
|---|---|
| 건물이 맞음 | 통. 남은 횟수가 줄수록 음이 높아진다 |
| 건물이 부서짐 | 뽁. 연달아 부술수록 음이 한 계단씩 올라간다. 다섯 음 음계라 어떻게 이어져도 어울린다 |
| 패들, 벽 | 낮고 둥근 통, 가벼운 톡 |
| 물에 빠짐, 물에서 나옴 | 퐁당, 뿅 |
| 좋은 아이템, 나쁜 아이템 | 딩동, 뚜웅 |
| 피버, 러시, 빨라짐 | 휘익 올라가는 소리 |
| 번개 | 찌직 |
| 공을 다 놓침, 게임 오버 | 내려가는 세 음 |
| 클리어 | 올라가는 네 음 |

배경 음악은 아직 없다. 건물 재질에 따라 타격음을 달리하는 것도 하지 않았다.

소리는 테스트에서 만들어지는지만 확인했다. 실제로 어떻게 들리는지는 귀로 확인해야 한다.

## 상표와 초상

실제 건물명과 지명은 사실 정보로 쓴다. 기업 로고와 간판은 그리지 않는다. 일부 유명 건물은 외관에 권리가 걸려 있을 수 있으므로, 랜드마크를 수작업 모델로 만들 때는 출시 전에 확인한다.
