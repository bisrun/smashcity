## 확인이 필요한 해석

- "축척 300m"를 **화면 가로에 담기는 실제 거리가 300m**라는 뜻으로 해석했다. OSM 웹 지도의 축척 막대가 300m로 표시되는 확대 수준을 뜻했다면 화면에 3km쯤이 담기므로 스테이지가 아니라 지구 크기에 해당한다.

## 제안 상태인 주요 설계

확정은 아니지만 다른 문서들이 전제로 삼고 있는 것들이다. 바뀌면 영향이 크다.

- 블록과 셀 구조 ([03](03_map_conversion.md))
- 판정은 2D, 표현은 3D ([02](02_core_gameplay.md), [12](12_tech_architecture.md))
- 클리어 조건은 100% 파괴가 아니다 ([02](02_core_gameplay.md))
- 아이템은 실제 시설에서 나온다 ([05](05_items.md))
- 도시 → 지구 → 스테이지 3단 구조, 서울 3지구 12스테이지 구성 ([04](04_stage_map.md))
- 스테이지는 미리 만들어 앱에 넣는다 ([13](13_data_pipeline.md))
- 장난감 디오라마 톤, 일부 시설은 파괴 제외 ([11](11_art_audio.md))
