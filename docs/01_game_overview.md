# 01 게임 개요

## 한 줄 정의

실제 도시의 지도 위에서 도로를 따라 공을 튕겨 건물을 부수는 3D 벽돌깨기.

## 기본 사항

| 항목 | 내용 | 상태 |
|---|---|---|
| 이름 | SmashCity (SimCity의 반대 느낌) | 확정 |
| 장르 | 벽돌깨기, 스테이지 클리어형 | 확정 |
| 표현 | 3D | 확정 |
| 플랫폼 | 안드로이드 먼저, 이후 아이폰 | 확정 |
| 개발 도구 | Flutter | 확정 |
| 배경 데이터 | OpenStreetMap | 확정 |
| 화면 방향 | 세로 | 제안 |
| 플레이 시간 | 스테이지당 3~5분 | 제안 |

## 설계 기둥

기획이 갈릴 때 이 세 가지에 비추어 판단한다. [제안]

1. **지도가 곧 레벨 디자인이다.** 격자형, 방사형, 섬 같은 도시 형태의 차이가 플레이 차이가 된다. 지도를 임의로 고쳐 재미를 만들지 않고, 재미있는 지도를 고른다.
2. **지역 지식이 실력이다.** 아이템은 실제 그 자리의 시설에서 나온다. 동네를 아는 사람이 먼저 찾는다.
3. **막힌 도시가 뚫린다.** 좁은 도로에서 시작해 블록이 무너질수록 공간이 열린다. 일부 스테이지에서는 이 해방감이 한순간에 터진다.

## 코어 루프

```
도시 선택 → 지구와 스테이지 선택 → 플레이 → 결과(점수, 별) → 다음 스테이지 해금
                              ↑                          │
                              └── 재도전(숨은 아이템, 별 3개) ┘
```

플레이 한 판의 흐름은 다음과 같다.

1. 패들에서 공을 발사한다.
2. 공이 도로를 따라 튀며 건물을 부순다. 부서진 건물에서 아이템이 나오기도 한다.
3. 블록이 무너지면서 통로가 넓어지고 더 깊은 곳에 닿을 수 있게 된다.
4. 랜드마크를 부수거나 목표 파괴율에 도달하면 클리어한다.

## 타깃 [제안]

- 짧은 시간에 한 판씩 하는 캐주얼 플레이어.
- 자기가 아는 동네, 가 본 도시가 나오면 반응하는 사람. 스크린샷 공유가 유입 경로가 된다.

## 범위

도시는 지구로 쪼개고, 지구 안에 스테이지를 둔다. [확정] 구조와 판 크기는 [04 스테이지 맵 기획](04_stage_map.md)에 있다.

첫 출시 범위는 아직 정하지 않았다. [미결정]

- 안 A: 서울의 3개 지구(잠실, 강남, 홍대), 지구당 4개로 12 스테이지. 권장.
- 안 B: 서울의 1개 지구(잠실) 4 스테이지로 먼저 내고 지구를 추가한다.
- 안 C: 서울과 뉴욕 두 도시.

포함하지 않는 것(첫 출시 기준, 제안): 멀티플레이, 사용자가 임의 지역을 골라 스테이지로 만드는 기능, 실시간 지도 다운로드.
