## 상태 표기

모든 기획 항목에는 상태를 붙인다. 제안을 확정으로 착각하고 구현하는 일을 막기 위해서다.

- **[확정]** 기획자가 정한 것. 바꾸려면 결정 기록에 남긴다.
- **[제안]** 초안 작성자가 낸 안. 검토 전이며 바뀔 수 있다.
- **[미결정]** 선택지만 나열된 상태. 결정이 필요하다.

상태가 바뀌면 해당 문서와 [90 결정 기록](90_decision_log.md)을 함께 고친다.

## 작성 규칙

- 한 문서는 한 가지 질문에 답한다. 다른 문서의 내용은 복사하지 않고 링크한다.
- 숫자(점수, HP, 속도)는 표로 적고, 실제 값은 코드가 아닌 데이터 파일에 둔다. 문서의 숫자는 초기값이며 밸런싱으로 바뀐다.
- 새 스테이지는 [stages/_template.md](stages/_template.md)를 복사해 쓴다.
- 용어는 [91 용어집](91_glossary.md)의 표기를 따른다.
