# 08 점수 관리

점수, 콤보, 별, 기록 저장을 정의한다.

이 문서의 항목은 모두 [제안]이다. 숫자는 초기값이며 데이터 파일에서 조정한다.

## 점수의 역할

- 클리어 여부와 별개로 "얼마나 잘 깼는가"를 보여 준다.
- 같은 스테이지를 다시 하게 만드는 이유가 된다.
- 해금에는 점수가 아니라 별을 쓴다. 점수는 기록 경쟁용이다.

## 점수 항목

| 항목 | 점수 | 비고 |
|---|---|---|
| 벽돌 타격 | 10 | HP가 남은 벽돌을 맞힐 때 |
| 벽돌 파괴 | 100 × 최대 HP | |
| 블록 클리어 | 500 + 100 × 블록의 건물 수 | 블록의 마지막 건물을 부술 때 |
| 아이템 획득 | 300 | 패들로 받았을 때 |
| 숨은 아이템 첫 발견 | 1,000 | 그 스테이지에서 처음 찾았을 때만 |
| 랜드마크 파괴 | 5,000 | 스테이지별 조정 가능 |
| 도미노 | 쓰러진 건물 수 × 300 | |
| 터짐 | 3,000 고정 | 아래 "터짐 중 점수" 참고 |

## 콤보

공이 패들에 닿지 않고 연속으로 벽돌을 부수면 배율이 오른다.

- 파괴 1회마다 배율 +0.1, 최대 5배.
- 공이 패들에 닿으면 1배로 돌아간다. 물에 빠졌을 때도 1배로 돌아간다.
- 공이 여러 개일 때 콤보는 공마다 따로 센다.
- 배율은 벽돌 파괴와 블록 클리어 점수에만 적용한다.

공이 블록 안쪽으로 들어가 오래 튀는 상황을 보상하는 규칙이다.

## 터짐 중 점수

터짐으로 생긴 임시 공은 콤보를 쌓지 않고, 벽돌 파괴 점수를 배율 1로 받는다. 대신 고정 보너스를 준다. 터짐 한 번이 점수 전체를 좌우하지 않게 하기 위해서다.

## 클리어 보너스

| 항목 | 점수 |
|---|---|
| 빠지지 않음 | 한 번도 빠지지 않으면 6,000. 빠질 때마다 2,000씩 준다 (실패 조건 결정에 따라 바뀜) |
| 시간 | (기준 시간 - 클리어 시간) × 20, 최소 0 |
| 파괴율 | 파괴율(%) × 50 |

기준 시간은 스테이지마다 정한다.

## 별

| 별 | 조건 |
|---|---|
| ★ | 클리어 |
| ★★ | 클리어 + 파괴율 90% |
| ★★★ | 클리어 + 파괴율 100% |

별 3개 조건은 정해지지 않았다. [미결정]

- 안 A: 파괴율 100%. 직관적이지만 마지막 벽돌을 찾아 헤매게 된다.
- 안 B: 스테이지별 목표 점수. 콤보와 시간까지 반영하지만 조건이 한눈에 안 들어온다.
- 안 C: 파괴율 90% + 한 번도 빠지지 않고 클리어.

## 코인 [미결정]

점수와 별도의 재화를 둘지는 [09 진행과 메타](09_progression_meta.md)의 수익화 결정에 따른다. 아이템 목록의 "코인 배율"은 코인을 두기로 할 때만 유효하다.

## 기록

스테이지마다 다음을 저장한다.

- 최고 점수
- 최고 별
- 최단 클리어 시간
- 최고 파괴율
- 찾은 숨은 아이템 목록

## 결과 화면에 보여 줄 것

1. 별
2. 점수 합계와 항목별 내역
3. 최고 기록 갱신 여부
4. 찾은 아이템 수 / 전체 아이템 수

## 판정의 재현성

점수 계산은 `lib/game/sim` 안에서만 한다. 같은 입력이면 같은 점수가 나와야 봇 검증과 리플레이가 가능하다. 온라인 순위표를 넣는다면 서버에서 입력 기록을 재생해 점수를 검증할 수 있다.
