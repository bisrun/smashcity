# 16 게임 공간 구조

게임이 어떤 공간으로 이루어지고 그 사이를 어떻게 오가는지 정의한다. 판 안의 규칙은 [02 코어 게임플레이](02_core_gameplay.md)에, 화면 하나하나의 생김새는 [10 UX와 UI](10_ux_ui.md)에 있다.

게임 공간을 로그인, 메인 메뉴, 게임방, 설정, 캐릭터로 넓혀 전체 구조를 기획한다. [확정] (2026-11-25) 아래의 세부는 사용자가 든 예를 바탕으로 쓴 초안이며 따로 표시하지 않은 항목은 모두 [제안]이다.

지금 구현된 것은 로그인(시나리오용), 메인 메뉴, WORLD TOUR(지역 선택), 스테이지 지도, 플레이, OPTIONS, DEV ROOM이다. 출발 준비, CREW, TROPHIES, RANKING, 시작 화면, 일시정지는 아직 없다. 메인 메뉴의 CREW, TROPHIES, RANKING 단추는 "준비 중"이라고만 알린다.

## 공간의 이름

공간의 이름은 영어로 쓴다. [확정] (2026-11-25) 이름 자체는 게임에 어울리게 지은 것이며 바꿀 수 있다. [제안] 이 문서의 나머지에서 한글 이름과 영어 이름은 같은 공간을 가리킨다.

| 한글 이름 | 화면에 쓰는 이름 | 뜻 |
|---|---|---|
| 게임방 | WORLD TOUR | 세계의 도시를 돌며 부순다 |
| 캐릭터 | CREW | 철거 대장과 탈것, 장비 |
| 설정 | OPTIONS | |
| 도감 | TROPHIES | 부순 랜드마크 |
| 순위 | RANKING | 이미 쓰던 이름 |
| 개발자 창 | DEV ROOM | 개발과 테스트용. 아래 참고 |

CREW의 탭은 CAPTAIN(내 정보), RIDES(탈것과 꾸밈), GEAR(소지품), RECORDS(기록)로 한다. [제안]

## 전체 지도

```

                              │                                              └ 일시정지
                              ├─ 캐릭터 ┬ 내 정보
                              │         ├ 탈것과 꾸밈
                              │         ├ 소지품
                              │         └ 기록
                              ├─ 설정
                              ├─ 도감
                              └─ 순위
```

| 공간 | 하는 일 | 상세 |
|---|---|---|
| 시작 화면 | 로고를 보여 주고 저장을 읽는다 | 이 문서 |

| 캐릭터 | 내 정보, 탈것, 소지품을 보고 고친다 | [18 캐릭터와 소지품](18_character_items.md) |
| 설정 | 게임의 기본 설정 | 이 문서 |

## 공간을 나누는 원칙

1. **판까지 세 번 안에 간다.** 이어 하는 사람은 메인 메뉴의 PLAY 한 번으로 마지막에 하던 스테이지의 출발 준비에 닿는다. 지역과 스테이지를 고르는 길은 그 옆에 따로 둔다.
2. **메인 메뉴의 단추는 다섯 개를 넘기지 않는다.** 공간이 늘면 단추를 더하지 않고 기존 공간 안에 탭으로 넣는다.
3. **판 밖의 것이 판정을 바꾸려면 한 군데로만 들어간다.** 캐릭터와 소지품이 판에 주는 영향은 판을 시작할 때 넘기는 설정 하나로 모은다([18](18_character_items.md)). 봇 검증과 난이도 등급이 여기에 달려 있다.
4. **서버가 없어도 끝까지 할 수 있다.** 로그인과 온라인 기능은 얹는 것이고, 꺼져 있어도 100 스테이지를 모두 할 수 있다.

## 시작 화면과 로그인

- 시작 화면은 로고와 "TAP TO START"다. 뒤에서 저장을 읽고, 계정이 연결되어 있으면 저장을 맞춘다.
- 처음 켠 사람에게만 로그인 화면이 뜬다. 다음부터는 건너뛴다.
- 게스트로 바로 시작하고 나중에 계정을 연결한다. [확정] 상세는 [17 계정과 저장](17_account_save.md)에 있다.
- 지금의 로그인 화면은 시나리오용이다. 단추 둘(SIGN IN WITH GOOGLE, PLAY AS GUEST) 가운데 어느 것을 눌러도 게스트로 지나간다. OPTIONS의 LOG OUT을 누르면 다시 볼 수 있다.

## 메인 메뉴

게임의 얼굴이다. 목록이 아니라 장면으로 만든다.

- **배경**: 마지막에 한 지역의 도시 모형이 천천히 돈다. 지역 테마([11](11_art_audio.md))의 색이 그대로 보인다. 내 탈것(배 또는 버스)이 앞에 떠 있다.
- **위쪽 띠**: 왼쪽에 내 얼굴과 이름, 레벨. 누르면 캐릭터로 간다. 오른쪽에 가진 재화(재화를 두기로 하면)와 설정 단추.
- **가운데 아래**: 큰 PLAY 단추. 그 위에 "서울 3/10 · 강남"처럼 이어 할 곳을 쓴다.
- **아래 띠**: 게임방(지역 고르기), 캐릭터, 도감, 순위.

| 단추 | 가는 곳 | 비고 |
|---|---|---|
| PLAY | 이어 할 스테이지의 출발 준비 | 가장 크게 |
| 게임방 | 지역 선택 | |
| 캐릭터 | 캐릭터 | 위쪽 띠의 얼굴과 같은 곳 |
| 도감 | 도감 | |
| 순위 | 순위 | |
| 톱니 | 설정 | 위쪽 띠 |

메인 메뉴에 더 두는 공간은 도감과 순위뿐이다. [확정] 상점, 우편함, 출석, 일일 과제는 수익화([09](09_progression_meta.md))가 정해진 뒤에 필요한 것만 더한다.

## 게임방

지역과 스테이지를 고르고 판을 시작하는 공간이다. 네 단계로 이루어진다.

게임방은 혼자 스테이지를 고르는 공간이다. [확정] 여럿이 모이는 방은 만들지 않는다.

### 1. 지역 선택

- 세계 지도 위에 지역 10곳이 건물 모형으로 서 있다([04](04_stage_map.md)의 순서).
- 지역마다 이름, 모은 별(예: 18/30), 깬 스테이지 수를 쓴다.
- 잠긴 지역은 회색이고 여는 조건을 쓴다. 해금 규칙은 [09](09_progression_meta.md)에 있다.
- 지금 구현은 지도가 아니라 단추 열 개의 목록이다. 앞 지역을 다 깨면 다음 지역이 열린다. 별이 생기면 별로 여는 규칙으로 바꾼다.
- 좌우로 넘기거나 지도에서 직접 누른다.

### 2. 스테이지 지도

지금 구현된 레벨 길 화면이다([10](10_ux_ui.md)). 지역마다 스테이지 10개가 길 위에 늘어선다. 바뀌는 것은 두 가지다.

- 위쪽에 뒤로 가기(지역 선택)를 둔다.
- 스테이지 단추를 누르면 바로 시작하지 않고 출발 준비가 뜬다.

### 3. 출발 준비

스테이지를 누르면 아래에서 올라오는 판이다. 판을 시작하기 전에 알아야 할 것과 고를 것을 모은다.

| 자리 | 내용 |
|---|---|
| 위 | 스테이지 이름, 지도 미리보기, 목표 랜드마크 |
| 가운데 | 난이도 등급(1~10), 내 최고 점수와 별, 이 스테이지의 순위 상위 3 |
| 아래 | 내 탈것, 가져갈 출발 아이템([18](18_character_items.md)) |
| 맨 아래 | START |

출발 아이템을 두지 않기로 하면 아래 칸은 탈것만 보여 준다.

### 4. 플레이와 결과

- 플레이와 일시정지는 [10](10_ux_ui.md)을 따른다. 일시정지에는 계속, 다시 하기, 설정, 나가기(스테이지 지도)가 있다.
- 결과는 스테이지 지도 위에 얹힌다. 점수, 별, 순위, 얻은 것(경험치, 재화, 새 도감 항목)을 보여 주고 다음 스테이지, 다시 하기, 지도로를 둔다.
- 지역의 열 번째 스테이지를 깨면 지역 완료 연출을 하고 지역 선택으로 돌아가 다음 지역을 연다.

## 설정

| 묶음 | 항목 | 기본값 |
|---|---|---|
| 소리 | 배경음 크기, 효과음 크기 | 각각 80% |
| 느낌 | 진동, 화면 흔들림 | 켬 |
| 조작 | 끄는 민감도 (0.8~2.0배) | 1.25배 |
| 화면 | 화질 (낮음 / 보통 / 높음), 프레임 제한 (30 / 60) | 기기에 맞춰 자동 |
| 언어 | 한국어, 영어 | 기기 언어 |
| 계정 | 연결된 계정, 계정 연결, 로그아웃, 내 데이터 지우기 | [17](17_account_save.md) |
| 정보 | 버전, 데이터 출처(© OpenStreetMap contributors), 쓴 재료의 이용 조건, 개인정보 처리방침 | |

- 설정은 메인 메뉴와 일시정지 양쪽에서 열린다. 일시정지에서는 소리, 느낌, 조작만 보여 준다.
- 설정은 기기에 딸린 것이다. 계정을 따라 다른 기기로 옮기지 않는다.
- 민감도와 화질의 숫자는 데이터 파일에 둔다.

## DEV ROOM

개발과 테스트에 필요한 설정을 넣는 창이다. [확정] (2026-11-25) 예쁘지 않아도 되고 명확하면 된다. [확정]

- **여는 법**: OPTIONS 화면에서 위쪽 띠를 왼쪽에서 오른쪽으로 끌고, 오른쪽 위를 빠르게 열 번 두드린다. [확정]
- **지금 있는 기능**: 모든 스테이지를 지역별로 보여 주고, 누르면 바로 그 스테이지를 시작한다. [확정] 줄마다 번호, 이름, 목표 등급, 기준선(강 또는 도로), 깼는지를 쓴다.
- 여기서 들어간 판은 기록에 남기지 않고 진행도 열지 않는다. 끝나면 DEV ROOM으로 돌아온다. [제안]

숨긴 동작의 세부 값은 다음과 같다. [제안] 코드는 `src/ui/secret_gesture.gd`에 있다.

| 항목 | 값 |
|---|---|
| 위쪽 띠 | 화면 높이의 위 18% |
| 끌기 | 화면 폭의 왼쪽 35% 안에서 시작해 오른쪽 35% 안에서 끝남 |
| 두드리는 자리 | 위쪽 띠의 오른쪽 40% |
| 두드림 사이 | 0.6초 안. 넘으면 처음부터 |
| 끌고 나서 첫 두드림까지 | 5초 안 |

이 동작이 눌리지 않도록 OPTIONS의 위쪽 띠에는 단추를 두지 않는다. 출시판에서 DEV ROOM을 막을지는 출시 준비 때 정한다.

## 오가는 규칙

- 안드로이드의 뒤로 단추는 한 단계 위 공간으로 간다. 메인 메뉴에서는 "끝낼까요?"를 묻는다. 플레이 중에는 일시정지를 연다. 지금 구현은 메인 메뉴에서 묻지 않고 끝내며, 플레이 중에는 아무 일도 하지 않는다(일시정지가 아직 없다).
- 공간 사이의 전환은 0.25초 안팎으로 짧게 한다. 판으로 들어갈 때만 카메라가 도시로 내려가는 연출을 쓴다.
- 앱이 뒤로 갔다가 돌아오면 플레이는 일시정지 상태로 돌아온다. 판의 중간 상태는 저장하지 않는다.
- 어느 공간에서든 위쪽 띠의 집 단추로 메인 메뉴에 간다(플레이 중 제외).

## 구현 구조

- 공간 하나가 화면 하나다. `src/ui/screens/` 아래에 공간마다 스크립트를 둔다. 화면은 스스로 다른 공간을 열지 않고 어디로 가려는지만 알린다.
- 지금은 `src/main.gd`가 그 알림을 받아 화면을 바꾼다. 스테이지를 바꿀 때는 장면을 다시 부르며, 다시 부른 뒤에 보여 줄 공간과 스테이지는 `src/ui/session.gd`에 적어 둔다.
- 화면이 더 늘면 전환을 따로 떼어 낸다(`src/ui/navigator.gd`). `src/main.gd`에는 판 진행만 남긴다.
- 설정은 `src/meta/settings_data.gd`가 `user://settings.json`에 남긴다.
- 판정(`src/sim`)은 이 구조를 모른다. 화면은 스테이지 id와 시작 설정을 넘기고 결과를 돌려받는다.

## 만드는 순서

| 단계 | 내용 | 서버 |
|---|---|---|
| 1 뼈대 | 시작 화면, 메인 메뉴, 지역 선택, 출발 준비, 설정, 화면 전환 | 필요 없음 |
| 2 캐릭터 | 내 정보, 레벨, 탈것 고르기, 기록 | 필요 없음 |
| 3 소지품 | 재화, 출발 아이템, 꾸밈 모으기 | 필요 없음 |
| 4 계정 | 로그인, 저장 맞추기, 온라인 순위 | 필요 |

1단계에서 남은 것은 시작 화면, 출발 준비, 일시정지, 세계 지도 모양의 지역 선택이다. 4단계의 구글 계정 연결은 할 일로 남겨 두었다.
