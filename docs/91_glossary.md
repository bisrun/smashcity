# 91 용어집

문서와 코드에서 같은 말을 같은 뜻으로 쓰기 위한 목록이다. 코드 식별자는 영문 표기를 따른다.

| 용어 | 영문 | 뜻 |
|---|---|---|
| 도시 | city | 스테이지 묶음. 월드에 해당한다 |
| 스테이지 | stage | 한 판. 도시 안의 동네 하나 |
| 판 크기 | board size | 판이 담는 실제 범위. OSM 축척 막대 300m(줌 15) 기준으로 약 1.5km × 2.6km |
| 중력 | gravity | 공을 패들 쪽으로 당기는 힘. 스테이지별 환경 변수 |
| 판 | board | 스테이지의 플레이 영역 |
| 통로 | corridor | 공이 다닐 수 있는 면. 큰 도로를 넓혀 만든다 |
| 블록 | block | 통로로 둘러싸인 영역 |
| 셀 | cell | 블록을 작은 길로 쪼갠 구획. 판정상의 벽돌 한 개. 화면에서는 두툼한 받침 블록 하나로 그린다 |
| 벽돌 | brick | 부술 수 있는 대상. 셀 하나와 그 안의 건물들 |
| 랜드마크 | landmark | 스테이지의 목표가 되는 보스 벽돌 |
| 기준선 | baseline | 패들이 움직이는 선. 공이 이 아래로 빠지면 잃는다 |
| 패들 | paddle | 플레이어가 조작하는 막대 |
| 해저드 | hazard | 공이 들어가면 불리해지는 영역. 호수에 빠진 공은 아무 방향으로나 튀어 오른다 |
| 워프 | warp | 지하철역 사이의 순간 이동 |
| 스피너 | spinner | 공의 방향을 트는 기믹. 회전교차로 |
| 핀 | pin | 1타에 사라지는 작은 장애물. 공원의 나무 |
| 숨은 아이템 | hidden item | 실제 시설 자리의 건물 안에 들어 있어 부숴야 나오는 아이템 |
| 상상 아이템 | imagined item | 지도에 없는 것을 지어내 판 위에 올려놓은 아이템. 처음부터 보인다 |
| 꾸밈 | decor | 나무, 숲처럼 게임 규칙에 영향을 주지 않는 장식 |
| 빠짐 | fall | 공이 호수에 들어가는 일. 공은 잃지 않고 콤보가 끊긴다 |
| 카타르시스 | catharsis | 터짐과 도미노를 아우르는 말 |
| 코어 | core | 터짐이 일어나는 닫힌 공간 |
| 터짐 | burst | 코어가 충전되어 공이 쏟아지고 구역이 비워지는 사건 |
| 임시 공 | shrapnel ball | 터짐으로 생겨 일정 시간 뒤 사라지는 공 |
| 도미노 | domino | 건물이 쓰러지며 이웃 건물을 연쇄로 부수는 사건 |
| 콤보 | combo | 공이 패들에 닿지 않고 연속으로 벽돌을 부순 횟수 |
| 파괴율 | destruction rate | 부순 벽돌 수 ÷ 부술 수 있는 전체 벽돌 수 |
| 판정 | sim | 2D 평면에서 도는 게임 규칙 계산. 화면 표현과 분리된다 |
| 베이킹 | baking | OSM 데이터를 스테이지 파일로 변환하는 작업 |
| 봇 | bot | 화면 없이 판정만 돌려 스테이지를 검증하는 자동 플레이어 |
