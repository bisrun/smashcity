# [도시] [번호] [지역명]

상태: 초안 / 검토 중 / 확정

## 요약

| 항목 | 내용 |
|---|---|
| 스테이지 ID | 예: `seoul/jamsil` |
| 중력 | 없음 / 약함 |
| 지도 범위 | 기준 좌표와 판의 실제 가로, 세로. 크기 기준은 [04](../04_stage_map.md) |
| 지도 회전 | 화면 위쪽이 가리키는 방위 |
| 도시 형태 | [04](../04_stage_map.md)의 형태 분류 |
| 목표 | 랜드마크 파괴 / 파괴율 N% |
| 난이도 | 1~10 ([07](../07_stage_leveling.md) 기준) |
| 목표 플레이 시간 | 분 |

## 이 스테이지의 재미

한두 문장으로 쓴다. 다른 스테이지와 무엇이 다른가.

## 배치

지도 스케치나 스크린샷을 넣고 아래를 표시한다.

- 패들 기준선
- 주요 통로 (공이 주로 다니게 될 대로)
- 랜드마크
- 해저드 (물)
- 기믹 (워프, 스피너)

## 벽돌

건물 수, 셀 수, 셀 넓이 중앙값, HP 분포, 통로 면적 비율을 적는다. 베이킹 결과에서 가져온다.

## 숨은 아이템

| 위치 (실제 시설명) | 아이템 | 찾기 난이도 |
|---|---|---|

## 카타르시스

없으면 "없음"이라고 쓴다. 있으면 [06](../06_catharsis.md)의 유형과 함께 아래를 쓴다.

- 위치와 그곳이 닿기 어려운 이유
- 닿기 위해 플레이어가 먼저 해야 하는 일
- 터진 뒤 판이 어떻게 바뀌는가

## 예상 플레이 흐름

초반, 중반, 후반으로 나누어 플레이어가 무엇을 하게 되는지 쓴다.

## 밸런스 값

기본값과 다른 것만 쓴다 (공 속도, 패들 폭, 중력).

## 검증 결과

봇 시뮬레이션과 실제 플레이 테스트의 클리어율, 평균 시간, 발견된 문제를 기록한다.
