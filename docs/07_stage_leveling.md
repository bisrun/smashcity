# 07 스테이지 레벨링

난이도를 무엇으로 조절하고, 스테이지가 진행되면서 어떻게 올리는지 정의한다.

따로 표시하지 않은 항목은 모두 [제안]이다.

## 난이도 변수

지도 자체는 고치지 않는다. 난이도는 어디를 잘라 쓰느냐와 아래 변수로 조절한다.

| 변수 | 쉬움 | 어려움 | 조절 방법 |
|---|---|---|---|
| 통로 폭 | 넓다 | 좁다 | 지역 선택, 도로 폭 배율 |
| 벽돌 크기 | 크고 적다 | 작고 많다 | 지역 선택, 판 크기 등급, 건물 합치기 기준 |
| 벽돌 HP | 낮다 | 높다 | HP 배율 |
| 물의 비율 | 없다 | 많다 | 지역 선택 |
| 목표까지의 깊이 | 얕다 | 깊다 | 지도 범위와 회전 |
| 중력 | 약함 | 없음 | 스테이지 환경 변수 [확정] |
| 공 속도 | 느리다 | 빠르다 | 스테이지 값 |
| 패들 폭 | 넓다 | 좁다 | 스테이지 값 |
| 아이템 수 | 많다 | 적다 | 기획자 배치 |
| 시작 라이프 | 3 | 3 | 고정. 라이프로 난이도를 조절하지 않는다 |

중력은 난이도보다 **판의 성격**을 바꾸는 변수다. 약한 중력에서는 공이 알아서 돌아오므로 편하지만 위쪽 깊은 곳에 닿기 어렵다. 중력이 없으면 공이 오래 위에서 놀아 깊은 곳을 잘 부수지만 궤적을 읽는 힘이 필요하다. 그래서 위 표의 방향은 대체로 그렇다는 뜻이고, 스테이지마다 봇으로 확인한다.

## 난이도 등급

스테이지마다 1~10 등급을 매긴다. 등급은 감으로 정하지 않고 봇 시뮬레이션 결과로 정한다.

| 등급 | 봇 클리어율 | 사람 첫 시도 클리어율 목표 |
|---|---|---|
| 1~2 | 95% 이상 | 90% |
| 3~4 | 80~95% | 70% |
| 5~6 | 60~80% | 50% |
| 7~8 | 40~60% | 30% |
| 9~10 | 40% 미만 | 15% |

봇과 사람의 대응 관계는 플레이 테스트로 보정한다.

## 요소 도입 순서

한 스테이지에서 새 요소는 하나만 가르친다. 물, 다리, 코어처럼 함께 있어야 뜻이 통하는 것은 묶어서 하나로 본다.

| 스테이지 | 새 요소 |
|---|---|
| 잠실-1 | 패들, 공, 벽돌, 블록 |
| 잠실-2 | 숨은 아이템 |
| 잠실-3 | 랜드마크 |
| 잠실-4 | 물과 다리, 코어와 터짐 |
| 강남-1 | 중력 없는 판, 워프 |
| 강남-2 | 높은 HP, 도미노 |
| 강남-3 | 부술 수 없는 벽돌 |
| 강남-4 | 콤보 |
| 홍대-1 | 작은 벽돌 |
| 홍대-2 | 공원, 핀 |
| 홍대-3 | 스피너 |
| 홍대-4 | 종합 |

## 난이도 곡선

곧게 올리지 않고 톱니 모양으로 올린다. 지구 안에서 오르고, 지구가 바뀌면 한두 등급 내려 시작한다. 새 형태에 적응할 시간을 주기 위해서다.

| 스테이지 | 등급 | 역할 |
|---|---|---|
| 잠실-1 한강변 아파트 단지 | 1 | 튜토리얼 |
| 잠실-2 잠실새내 먹자골목 | 2 | 아이템 학습 |
| 잠실-3 종합운동장 | 3 | 첫 랜드마크 |
| 잠실-4 석촌호수 | 5 | 지구 피날레, 터짐 |
| 강남-1 강남역 사거리 | 3 | 새 지구, 중력 없는 판에 적응 |
| 강남-2 테헤란로 | 5 | |
| 강남-3 코엑스와 봉은사 | 5 | |
| 강남-4 가로수길 | 6 | 지구 피날레 |
| 홍대-1 홍대입구역 | 5 | 새 지구 |
| 홍대-2 연남동 경의선숲길 | 6 | |
| 홍대-3 걷고싶은거리 | 7 | 가장 어려운 판 |
| 홍대-4 합정과 선유도 | 8 | 도시 피날레, 터짐 |

## 카타르시스 배치

- 터짐은 지구의 마지막 스테이지에 둔다. 어렵게 쌓인 긴장을 푸는 자리다. 모든 지구에 넣지는 않는다.
- 도미노는 첫 스테이지에 작게 넣어 "이 게임에는 이런 순간이 있다"는 것을 일찍 보여 준다.
- 서울 12개 스테이지 중 터짐 2개, 도미노 2개다.

## 한 스테이지 안의 흐름

| 구간 | 시간 | 상태 |
|---|---|---|
| 초반 | 0~1분 | 통로가 좁다. 가까운 블록부터 연다 |
| 중반 | 1~3분 | 판이 넓어지고 아이템이 나온다. 공이 빨라진다 |
| 후반 | 3~5분 | 목표를 노린다. 카타르시스가 있으면 여기서 일어난다 |

공 속도는 시간에 따라 3단계로 오른다. 판이 넓어지면 공의 왕복 시간이 길어지므로 속도를 올려 리듬을 유지한다.

## 검증 절차

1. 스테이지를 베이킹한다.
2. 봇으로 1,000판을 돌려 클리어율, 평균 시간, 공이 돌아오지 않은 최장 시간을 잰다.
3. 목표 등급의 범위를 벗어나면 변수를 고쳐 다시 돌린다.
4. 사람이 플레이해 보정한다.

결과는 스테이지 기획서의 "검증 결과"에 적는다.
