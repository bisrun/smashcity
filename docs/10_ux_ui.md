# 10 UX와 UI

화면 흐름, 조작, HUD를 정의한다. 모든 항목은 [제안]이다.

## 화면 흐름

게임 공간을 넓힌 전체 구조(로그인, 메인 메뉴, 게임방, 캐릭터, 설정)는 [16 게임 공간 구조](16_game_structure.md)가 정한다. 아래는 그 전에 쓴 흐름이고 지금 구현된 범위다. 둘이 다르면 16을 따른다.

```
타이틀 → 도시 선택 → 스테이지 지도 → 플레이 → 결과가 얹힌 스테이지 지도
            │              │           │        ├→ 다음 스테이지
            └→ 도감         └→ 기록 보기  └→ 일시정지  └→ 다시 하기
            └→ 설정
```

| 화면 | 보여 주는 것 |
|---|---|
| 타이틀 | 로고, 시작 |
| 도시 선택 | 세계 지도 위의 도시들, 도시별 별 합계, 잠긴 도시의 해금 조건 |
| 스테이지 지도 | 길 위에 늘어선 스테이지, 남은 수, 순위. 아래 "스테이지 지도" 참고 |
| 플레이 | 판과 HUD |
| 일시정지 | 계속, 다시 하기, 나가기, 설정 |
| 결과 | [08 점수 관리](08_scoring.md)의 결과 항목 |
| 도감 | [09 진행과 메타](09_progression_meta.md)의 도감 |
| 설정 | 소리, 진동, 언어, 데이터 출처 표기 |

스테이지 선택 화면이 실제 지도 위에 놓이는 것이 이 게임의 얼굴이다. 목록이 아니라 지도로 고른다.

## 조작

- 한 손 엄지로 조작한다.
- 화면 어디든 닿은 채로 끌면 패들이 끈 만큼 움직인다. 닿는 순간에는 움직이지 않는다. [확정] 손가락이 패들 위에 있을 필요가 없으므로 패들을 가리지 않는다.
- 끄는 민감도는 손가락이 움직인 거리의 1.25배다. [제안]
- 탭: 공 발사, 자석 패들에서 공 놓기.
- 플레이 중 카메라 조작은 없다.

## HUD

화면 위쪽에 점수와 효과를 보여 주고, 지금 어느 스테이지인지 표시한다. [확정]

지금 구현은 다음과 같다. [제안] 위쪽의 둥근 흰 판 하나에 모았다.

| 자리 | 요소 | 움직임 |
|---|---|---|
| 왼쪽 | 스테이지 표지. "서울 1/6 · 잠실" | |
| 가운데 | 점수 | 한 번에 바뀌지 않고 빠르게 세어 올라간다. 오를 때 살짝 커졌다 돌아온다 |
| 오른쪽 | 남은 공. 공 모양 동그라미 | |
| 둘째 줄 | 목표 막대. 잠실은 타워의 남은 HP | |
| 둘째 줄 끝 | 콤보 배율 | 배율이 오르면 주황, 피버면 빨강에 "피버" 글자 |
| 셋째 줄 | 켜져 있는 아이템과 남은 시간. 불공, 넓은 패들, 마무리 | 켜져 있을 때만 보인다 |
| 화면 가운데 | 한마디. 받은 아이템, 피버, 마무리, 클리어 | 1.5초 떴다 사라진다 |

판을 가리지 않도록 HUD는 위쪽 가장자리에 모은다. 카메라는 화면 위쪽 13%를 HUD 자리로 비운다.

## 스테이지 지도

스테이지에서 스테이지로 넘어갈 때는 미니맵처럼 스테이지가 얼마나 남았는지 보여 준다. [확정]

처음 만든 화면은 뼈대는 맞았지만 디자인이 초보적이었다. 다른 캐주얼 게임의 레벨 길 화면처럼 다시 만들었다. [확정된 방향]

지금 구현은 다음과 같다. [제안]

- 배경은 하늘, 언덕, 풀밭이고 구름이 천천히 흐른다.
- 굽이진 길이 아래에서 위로 올라가고, 길가에 나무와 작은 집이 있다.
- 스테이지는 도톰한 둥근 단추다. 깬 곳은 초록 단추에 별, 이번에 할 곳은 숨 쉬듯 커졌다 작아지는 빨간 단추에 통통 튀는 표지, 못 가는 곳은 회색 단추에 자물쇠다.
- 단추 옆 이름표에 스테이지 이름과 최고 점수(BEST)를 쓴다.
- 위쪽 판에 도시 이름, "STAGE 1 / 6", 스테이지 수만큼 칸이 나뉜 진행 막대를 둔다.
- 판이 끝난 뒤에는 아래쪽 판에 CLEAR! 또는 GAME OVER, 점수, RANK를 함께 보여 준다.
- 아래에 도톰한 PLAY 단추가 있다. 화면 어디를 눌러도 시작된다.

특정 게임의 그림을 따라 그리지는 않았다. 레벨 길, 도톰한 단추, 별과 자물쇠라는 짜임만 따랐다.

앞서 적은 "도시 지도 위에 스테이지 범위가 사각형으로 보인다"는 화면은 만들지 않았다. 실제 지도 위에 올리는 것은 스테이지가 여럿 만들어진 뒤에 다시 본다.

## 점수 순위

점수 순위를 보여 준다. [확정]

- 스테이지마다 점수가 높은 순서로 20개까지 기기에 남긴다. 스테이지 지도 아래쪽에 위에서 다섯(결과가 함께 뜰 때는 셋)을 보여 준다. 1, 2, 3위는 금, 은, 동 표지이고 방금 낸 기록은 색 바탕으로 띄운다. [제안]
- 지금은 이 기기 안에서의 순위다. 다른 사람과 겨루는 순위는 서버가 있어야 해서 아직 없다. 넣는다면 이름 입력과 서버 쪽 점수 검증이 함께 필요하다([08 점수 관리](08_scoring.md)의 판정의 재현성). [미결정]

## 글의 말씨

순간의 임팩트와 효과를 알리는 말은 영어로 쓴다. [확정] FEVER!, CLEAR!, GAME OVER, MISS!, MULTI BALL!, FIRE BALL!, WIDE PADDLE!, 1 UP!, LIGHTNING!, FINALE!, PLAY, RANKING, BEST 같은 것들이다.

스테이지와 도시의 이름, 설명하는 글은 한글로 둔다. [제안]

## UI 재료

게임 UI 라이브러리를 찾아본 결과는 다음과 같다(2026-11-24 검색).

| 재료 | 내용 | 이용 조건 | 쓰는지 |
|---|---|---|---|
| [Jua](https://fontsource.org/fonts/jua/about) | 둥글둥글한 한글 글꼴. 우아한형제들 제작, 구글 폰트 제공 | SIL Open Font License 1.1 | 쓴다. `assets/fonts/` |
| [Kenney UI Pack](https://www.kenney.nl/assets/ui-pack) | 버튼, 판, 슬라이더 그림. 다섯 색 | CC0 | 아직 안 쓴다 |

지금 UI는 Godot의 기본 UI 부품에 둥근 판과 Jua 글꼴을 입혀 만들었다. 그림 조각을 가져오지 않아도 모양이 맞아서 UI Pack은 쓰지 않았다. 버튼이 늘어나 설정 화면 같은 것을 만들 때 다시 본다.

## 튜토리얼

글로 설명하지 않고 첫 스테이지의 배치로 가르친다. 새 요소가 처음 나올 때만 한 줄 안내를 띄운다.

## 접근성

- 색만으로 정보를 구분하지 않는다. 아이템은 색과 모양을 함께 쓴다.
- 진동과 화면 흔들림은 설정에서 끌 수 있다.
