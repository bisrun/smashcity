# 10 UX와 UI

화면 흐름, 조작, HUD를 정의한다. 모든 항목은 [제안]이다.

## 화면 흐름

```
타이틀 → 도시 선택 → 지구와 스테이지 선택 → 플레이 → 결과
            │              │                  │        ├→ 다음 스테이지
            └→ 도감         └→ 기록 보기         └→ 일시정지  └→ 다시 하기
            └→ 설정
```

| 화면 | 보여 주는 것 |
|---|---|
| 타이틀 | 로고, 시작 |
| 도시 선택 | 세계 지도 위의 도시들, 도시별 별 합계, 잠긴 도시의 해금 조건 |
| 지구와 스테이지 선택 | 도시 지도 위에 지구가 보이고, 지구를 누르면 확대되어 스테이지 범위가 사각형으로 보인다. 별, 최고 점수 |
| 플레이 | 판과 HUD |
| 일시정지 | 계속, 다시 하기, 나가기, 설정 |
| 결과 | [08 점수 관리](08_scoring.md)의 결과 항목 |
| 도감 | [09 진행과 메타](09_progression_meta.md)의 도감 |
| 설정 | 소리, 진동, 언어, 데이터 출처 표기 |

스테이지 선택 화면이 실제 지도 위에 놓이는 것이 이 게임의 얼굴이다. 목록이 아니라 지도로 고른다.

## 조작

- 한 손 엄지로 조작한다.
- 화면 아래쪽 어디든 드래그하면 패들이 손가락의 x 위치를 따라간다. 손가락이 패들을 가리지 않도록 패들은 터치 지점보다 위에 있다.
- 탭: 공 발사, 자석 패들에서 공 놓기.
- 플레이 중 카메라 조작은 없다.

## HUD

| 위치 | 요소 |
|---|---|
| 상단 왼쪽 | 라이프 |
| 상단 가운데 | 점수, 콤보 배율 |
| 상단 오른쪽 | 일시정지 |
| 상단 아래 | 목표 진행 (파괴율 또는 랜드마크 HP) |
| 패들 옆 | 작동 중인 아이템과 남은 시간 |
| 구석 | 방위 표시 |

판을 가리지 않도록 HUD는 위쪽 가장자리에 모은다.

## 튜토리얼

글로 설명하지 않고 첫 스테이지(잠실-1)의 배치로 가르친다. 새 요소가 처음 나올 때만 한 줄 안내를 띄운다.

## 접근성

- 색만으로 정보를 구분하지 않는다. 아이템은 색과 모양을 함께 쓴다.
- 진동과 화면 흔들림은 설정에서 끌 수 있다.
